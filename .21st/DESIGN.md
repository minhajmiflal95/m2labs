# M² Labs design context

The active app is React/Vite with React Router, existing Motion/GSAP, and local illustrations. Headings use Space Grotesk; body text uses Manrope; technical captions use IBM Plex Mono. The existing logo, every-refresh ident, cinematic homepage story and light/dark neumorphic themes must remain.

## Selected direction

Seven service-specific environments use original React/SVG compositions: Floating Design Studio, Living Software Architecture, Growth Intelligence, Connected Cloud Universe, Research Innovation Lab, Digital Operations Center and Connected Enterprise Ecosystem. Existing Reveal, Action, page transitions, native FAQs and service layouts are reused. All service platform assets are local and sourced from identified logo libraries or the vendor repository. Capabilities are never given fake platform logos.

Layouts stay editorial, spacious and restrained. Scene accents vary deliberately; page surfaces, typography and controls use the project tokens. Pointer tilt and data packets are decorative and respect reduced motion and the global pause. Nodes support hover, focus and tap. Examples are illustrative, never claimed client work. No unconfirmed 24/7 support or vendor partnerships are advertised.

## 21st workflow evidence

The installed 21st v0.5.0 UI-build and CLI-use skills were read. `21st init --design-context` created this context. Component search was attempted before implementation, but returned “Not signed in.” API_KEY_21ST is absent; no 21st MCP tools are exposed in this chat, and the MCP endpoint returns a network-proxy CONNECT 403. No remote catalog component was retrieved and no hosted generation was requested. The user's brief expressly permits original existing-stack components when 21st is unavailable.

Local `21st review` ran on the environment component, service page and scene stylesheet. It reported 36 informational hardcoded-colour notices and no automatic fixes. These are intentionally authored illustration palette/shadow values; the page theme and typography still use project tokens. Browser contrast checks cover the actual rendered result in both themes.
